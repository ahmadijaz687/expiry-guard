# LinkedIn Launch Assets: ExpiryGuard

## 1. Project Headline
**ExpiryGuard — Smart Kitchen Inventory & Cook-First Waste Avoidance Assistant**

## 2. Project Description (102 words)
The average household discards over $90 worth of forgotten groceries every month, driven by out-of-sight refrigeration and dinner decision fatigue. I designed and engineered ExpiryGuard, an offline-first web application that shifts grocery management from passive logging to proactive cooking. Built with React 19, TypeScript, and Tailwind CSS, ExpiryGuard pairs smart shelf-life presets with a Cook-First recommendation engine that suggests recipes specifically around ingredients expiring within 72 hours. An integrated Waste-Avoided Tracker quantifies rescued grocery dollars, diverted food weight, and averted CO₂e emissions. Verified with 100% test coverage across core calculation engines and zero external runtime dependencies.

## 6. Launch Post Draft (152 words)
Most household food waste doesn't happen out of negligence—it happens because refrigerators act like opaque storage units where leafy greens and proteins quietly reach expiration behind taller containers. When dinner time arrives, decision fatigue sets in, takeout gets ordered, and good food ends up in municipal landfills.

To solve this specific friction, I built ExpiryGuard.

Instead of operating like a tedious warehouse spreadsheet, ExpiryGuard uses research-backed shelf-life presets for quick entry and surfaces a Cook-First engine that clusters ingredients expiring in the next 72 hours into actionable dinner recipes. Every time an ingredient is cooked, the application quantifies the financial dollars saved and CO₂e emissions averted.

The application is built with TypeScript, React, and Tailwind CSS, featuring local-first persistence, dark/light themes, keyboard navigation, and full unit test coverage.
